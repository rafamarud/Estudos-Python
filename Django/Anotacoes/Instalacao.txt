1. Verificar o Python
py --version

E verificar o pip:

py -m pip --version

2. Instalar o Pipenv
O Pipenv acabou instalado no Python principal com:

py -m pip install --user pipenv

Para verificar:

py -m pip show pipenv

3. Criar/usar o ambiente virtual com Pipenv
py -m venv venv
O Pipenv criou o ambiente virtual do projeto. Depois, dentro de:

D:\Documents\Estudos-Python

usamos:

py -m pipenv install django

Esse é o comando importante: ele instalou o Django no ambiente virtual do projeto, não globalmente.

4. Verificar o Django
Fora do ambiente virtual:

py -m pipenv run python -m django --version

Resultado:

6.1.1

Ou, depois de entrar no ambiente:

py -m pipenv shell

podemos usar:

py -m django --version

Resultado:

6.1.1

5. Ver os pacotes instalados
O comando correto é:

pip freeze
